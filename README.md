# Door+ Wiki

Source of the Door+ documentation, published at https://cristiaaaaan.github.io/DoorPlus-Wiki/ from the
`gh-pages` branch.

```
pip install -r requirements.txt
mkdocs serve                 # local preview
mkdocs build --strict        # check links and anchors
mkdocs gh-deploy --strict    # build and publish to gh-pages
```

PDF export: run `mkdocs serve`, open `http://127.0.0.1:8000/DoorPlus-Wiki/print_page/` in Chrome with the
wiki in light mode (sun/moon button), then Print → Save as PDF, A4, background graphics on.
