# Door+ Wiki

Source of the Door+ documentation, published at https://cristiaaaaan.github.io/DoorPlus-Wiki/ by the
`Deploy wiki` workflow on every push to `main`.

Preview locally:

```
pip install -r requirements.txt
mkdocs serve
```

PDF export: run `mkdocs serve`, open `http://127.0.0.1:8000/DoorPlus-Wiki/print_page/` in Chrome with the
wiki in light mode (sun/moon button), then Print → Save as PDF, A4, background graphics on.
